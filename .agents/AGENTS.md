# AI Software Engineer Roadmap - Agent Rules & Context

This file contains project-scoped rules and instructions for AI agents working in this repository.

- **Owner:** Udit Thakur (4.5+ years experience in C#, .NET, SQL, Blazor, React, Python)
- **Mission:** Comprehensive AI Software Engineer Roadmap & Documentation Hub focusing on architecture, system design, domain-driven design (DDD), clean architecture, and agentic workflows over syntax grind.

## Engineering & Content Guidelines
1. **Style & Aesthetics:** Keep markdown clean, structured, and professional. Avoid excessive emoji or icon bloat.
2. **Architecture-First:** Code examples must adhere to SOLID, Clean Architecture, and Domain-Driven Design principles.
3. **AI Integration:** Focus on production-grade AI engineering patterns (MCP, RAG, tool calling, multi-agent orchestration).
4. **Directory Organization:**
   - `docs/`: Technical guides, architectural concepts, and roadmap modules.
   - `examples/`: Clean, runnable code snippets illustrating design patterns and AI integrations.
   - `projects/`: Multi-tier project implementations (beginner to real-world).
   - `interview/`: System design & architectural interview preparation.
   - `templates/`, `cheat-sheets/`, `diagrams/`, `prompts/`, `resources/`: Operational assets.

## Continuous Maintenance Rule
As discussions progress and new features/sections are added, update `.agents/AGENTS.md` to reflect new project decisions, conventions, and memory.
