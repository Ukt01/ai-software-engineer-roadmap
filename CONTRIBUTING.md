# Contributing Guidelines

Thank you for your interest in contributing to the **AI Software Engineer Roadmap**!

## Code of Conduct & Contribution Rules

1. **Branch Protection:** Direct pushes to `main` are restricted. All changes must be submitted via Pull Requests.
2. **Pull Requests:** 
   - Fork the repository and create a feature branch (`git checkout -b feature/amazing-addition`).
   - Keep commits focused and descriptive using [Conventional Commits](https://www.conventionalcommits.org/).
   - Open a PR against `main` for review.
3. **Quality & Standards:**
   - Keep documentation clean, structured, and free of excessive icon bloat.
   - Code snippets in `examples/` and `projects/` must follow SOLID, Clean Architecture, and Domain-Driven Design principles.
